# KORDON — concept

**Title**: KORDON (Russian for *cordon*)
**Studio**: Tras Bit  **Engine**: Unity 6 LTS  **Platform**: Windows x64
**Setting**: the Veransk corridor, a fictional industrial border region, 2026.
**Factions**: the Veransk Militia Front (VMF) holds the Zavod-7 works and the Kiln
site; the player is a contract operator working the corridor for a private
security outfit, not a national army.

## Tone

Grounded and procedural, not heroic. Radio traffic is terse, briefings are
written as operational orders, and the sound design leans on machinery, wind and
breath rather than music. There is no score in a match; the only music is the
menu bed.

Visual direction: overcast industrial realism — wet concrete, painted steel,
hazard stripes, sodium work lights, dust in the air. The bodycam treatment
(sensor grain, barrel distortion, chromatic edges, exposure flutter) is part of
the look and is always on, because the game is about being a body in a place, not
about piloting a camera.

## What is original

Everything: name, setting, factions, map layout, art, textures, sound, UI, code.
No asset, map, sound, model or line of code from any existing game is used. The
"bodycam feel" was used only as a reference for how much camera inertia and
sensor imperfection can carry tension; nothing visual was copied.

## Modes

| Mode | Players | Goal |
|---|---|---|
| **Free-for-All** (release mode) | 20 human slots, no bots | first operator to **50 personal kills** |
| **Operation Silent Kiln** (co-op) | 2–4 operators, AI hostiles | briefing, linked objectives, hold, evacuation |
| **Practice** (offline) | 1 | learn the map, recoil and the magazine system; clearly labelled, never substitutes for online play |

## Pillars

1. **Ammunition is knowledge.** You never see a live round count; you either
   remember your magazine or you stop and inspect it, and inspecting costs you.
2. **Weight and breath.** Movement is slow and inertial, stamina is short, and
   exhaustion, suppression and wounds all make the weapon worse.
3. **The camera is a body.** Constant inertia, sway and sensor noise, no toggle.
4. **Fair by construction.** No paid advantage, no unlock that changes a stat,
   no crosshair, no aim assist; the server decides every hit.
